# Muhammad Usama Ali - Professional Portfolio

Modern, high-performance personal portfolio website for **Muhammad Usama Ali**, Senior Android & Flutter Developer, Modern Web Developer, Creative Video Editor, and Social Media Strategist.

---

## 🌟 Key Features

1. **Multidisciplinary Positioning & Architecture:**
   - Highlights 2.5+ years of specialized mobile development (Kotlin & Flutter) with over **3,000,000 Play Store downloads**.
   - Dedicated showcase for **Mobile Engineering Architecture**, **Clean Code & Systems**, and **Play Store Deployments**.

2. **Visual Aesthetics & Motion:**
   - Dark/Light mode theme switch with `localStorage` memory and system-preference auto-detection.
   - Smooth 60fps ambient particle canvas that gracefully respects `prefers-reduced-motion`.
   - Scroll progress indicator, sticky glassmorphic navigation with scroll spy, and dynamic rotating role typewriter effect.
   - Interactive project filter tabs (All, Mobile Apps, Web, Cameras & Telemetry).
   - Rich interactive Project Case Study modal dialogs.
   - Interactive Weekly Social Media Content Planner with clickable schedule days.

3. **Recruiter & Client Double Funnel:**
   - Dual Resume Download Center with public-safe versions:
     - **Technical CV** (Android & Flutter Developer)
     - **Creative & SMM CV** (Video Editor & Social Media Manager)
   - Verified contact options: Direct Email with one-click copy, WhatsApp quick chat, and client-side validated contact inquiry form that pre-populates mailto & WhatsApp messages.

4. **Zero-Bloat Performance & Storage Compliance:**
   - Built with semantic HTML5, modern CSS3 custom properties (design tokens), and clean vanilla ES6 modules.
   - Requires zero heavy node_modules dependencies on the C: drive.
   - 100% self-contained on the `D:\portifolio` drive.

## 🚀 How to Run Locally

You can launch the portfolio using any local web server. The recommended, zero-install method uses Python (already installed on Windows):

### Option 1: Python HTTP Server (Recommended)
Open PowerShell and run:
```powershell
cd D:\portifolio
python -m http.server 8000
```
Then open your web browser and navigate to:
```
http://localhost:8000
```

### Option 2: VS Code Live Server
1. Open folder `D:\portifolio` in Visual Studio Code.
2. Right click `index.html` and click **Open with Live Server**.
